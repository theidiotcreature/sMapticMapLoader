# <img src="https://github.com/theidiotcreature/sMapticMapLoader/blob/main/data/gdpatch/mods/smaptic/icon.png" alt="mod icon" width="40"/> sMaptic Map Loader

sMaptic is a map loader mod for SNAPTIC Demo! Visit the homepage [here!](https://sMaptic.github.io)

This mod allows you to import maps in the form of .zip files that have been exported from the Godot editor directly into SNAPTIC, without touching any code or installing multiple mods! Maps can be shared and downloaded via the official [sMaptic Map Index](https://sMaptic.github.io/MapIndex), and imported in-game into your personal custom maps list. Custom maps are extremely flexible and can contain almost anything you can think of!

If you are a map developer who would like an in-depth tutorial on the sMaptic pipeline, or a mod developer who would like to expand on the systems of the mod, check out the [documentation.](https://sMaptic.github.io/Documentation)

Join the [SNAPTIC Modding](https://discord.gg/PgfbejJ8D) discord server for an [installation guide!](https://discord.com/channels/1558715375506563072/1566964824003452999/1566964824003452999)
